# 输入框附件与能力菜单、审批卡片

## 输入框

- 输入框「＋」打开附件与能力菜单，不再跳转设置。全局设置仍在左下角。
- 添加文件/文件夹：使用系统选择器，支持多选，规范化真实路径、去重、最多 20 项。
- 拖拽：从本机文件管理器拖入输入框；拖入高亮，完成后显示可移除标签。利用 Electron webUtils 取得真实文件路径，不信任网页自报的文件名。
- 使用插件：列出已配置 MCP 和启用的内置浏览器；未启用插件置灰，不通过选择偷偷启用插件。
- 使用 Skill：发现项目和用户 `.agents/skills/<name>/SKILL.md`、`.codex/skills/<name>/SKILL.md`，选择后作为原生 skill 输入传递；不等于安装远程 Skill。当前最多选择 10 个。
- 支持 Escape/点击菜单外关闭，插件与 Skill 子菜单返回、移除标签、发送成功清空、发送失败保留附件；切换项目/会话清空草稿附件，避免带到另一任务。
- 能力菜单打开时隐藏原生浏览器视图，避免菜单被 WebContentsView 遮挡。

文件采用本地引用方式：拖入时不会联网上传，不读取整个目录，也不把二进制文件原样塞进提示词。发送任务后，路径作为结构化上下文交给 Agent，通过文件工具按需读取；模型读取的内容仍会按当前模型服务的数据链路处理。暂未加入对象存储上传、附件内容快照、OCR 或独立图片预览。原文件若删除，发送时会报错并保留草稿。

插件选择是本轮工具使用意图，不是插件实际执行的保证，也不免除工具审批。Skill 路径及插件启用状态发送时由 Host 再次核对。新增附件不扩大沙盒权限。

## 审批卡片

采用靠近桌面工作台的中性深色卡片：图标/操作标题、审批原因、独立命令块、工作目录、详情折叠、底部拒绝和单次允许。

任务级同类命令/前缀授权归入折叠区域，保留前缀数组与作用期限说明。默认不展开更广授权选项。审批处理中禁止重复提交；失败显示错误，保留审批；显示待审批队列数量。

本轮改变呈现，不改变此前已经实现的权限策略。
