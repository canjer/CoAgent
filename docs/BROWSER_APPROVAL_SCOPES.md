# 浏览器任务级审批

浏览器 MCP 审批卡新增：

- **允许此次操作**：原有行为，参数精确匹配、单次有效。
- **本次任务允许同类请求**：同一个工具、同一 origin（协议、主机、端口）的后续请求自动审批。导航按目标 URL 的 origin 分类；点击、输入和快照按当前页面 origin 分类。工具或站点不同仍询问。
- **本次任务浏览器完全授权**：本次 run/turn 内全部现有浏览器工具自动审批。

“完全授权”仅覆盖浏览器工具审批，不更改网络资源域策略，不授权 shell、文件修改、其他 MCP、任意 JavaScript/CDP。浏览器网页内的数据仍是不可信输入。资源域授权仍通过独立确认操作。

## 生命周期

范围仅存于 Main 内存，不持久化；新任务、任务完成、停止、Host/runtime 断连、接管/交还时清空。侧边栏展示当前授权模式，点击「接管」可立即取消任务级授权并暂停浏览器。

自动审批不是跳过执行层：每次真实 Codex 审批仍由 Main 校验服务名、固定工具名、参数、任务状态与控制权，签发一次性精确参数授权，再通知 Host 接受该次请求。单次授权消费后失效。未知格式、未知工具、非浏览器请求不自动接受。Host 审批失败时撤销任务级授权。

当前仅在浏览器审批卡显示这些选项。命令/文件/第三方 MCP 保持原有审批流程。

## 开发验证

- `npm run check`：策略单测含不同工具/域名不复用、完全授权、清空和非浏览器请求排除。
- `npm run test:browser:service`：同类自动审批实际签发/消费，以及接管后撤销。
- `COAGENT_APPROVAL_MODE=all npm run test:desktop:browser`：真实 Codex + Chat 请求 navigate/snapshot/click，只点击首个完全授权按钮；后续工具成功，任务完成状态清零。
- `COAGENT_APPROVAL_MODE=similar npm run test:desktop:browser`：连续两次同站导航，首个点击同类授权，第二个自动通过；不同工具仍审批。
- `npm run test:desktop:browser`：原有逐次审批流程继续通过。

本轮不生成安装包。
